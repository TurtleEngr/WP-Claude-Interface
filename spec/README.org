* doc-WP-Claude-Interface
** This repo is for internal documentation, and generating new code with Claude
+ Local code: ~/ver/github/app/WP-Claude-Interface/
+ Repo: git@github.com:TurtleEngr/WP-Claude-Interface.git

** Usage
+ make query-prep
+ mv tmp/query-prep.tmp to query/FILE.org
+ # Add prompt at beginning of query/FILE.org
+ # cut/paste query/FILE.org all to Claude input
+ # cut/pastte Claude output to results/FILE.org
+ # put results/ files in results/FILE.zip

+ cd $(mSrc)
+ git flow feature start BRANCH
+ unzip results/FILE.zip

+ # Build, test, package in $(mSrc) 
+ # See directions in $(mSrc)/Makefile
+ # After $(mSrc) build works
+ # git flow feature finish BRANCH
+ # make package

+ make release publish
+ make clean
